# CS2 Optimizer (Counter-Strike 2 Diagnostics & Optimization)

Скрипт на PowerShell (`optimize_cs2.ps1`) для глубокой диагностики и оптимизации производительности Counter-Strike 2, а также системы Windows.

---

## 📌 Что изменяет и делает скрипт

1. **Очистка кэша шейдеров и временных файлов:**
   - Очищает кэш DirectX / Vulkan (`D3DSCache`, кэш NVIDIA DXCache / ComputeCache, AMD DxCache, Intel DxCache).
   - Удаляет аварийные дампы паданий CS2 (`cs2_*.dmp`).
   - Очищает локальный кэш Steam Workshop.

2. **Оптимизация системного отклика и сети (Windows Tweaks):**
   - Устанавливает `NetworkThrottlingIndex = 0xFFFFFFFF` (отключает сетевое дроттлирование для снижения задержек в играх).
   - Устанавливает `SystemResponsiveness = 0` (приоритет системных ресурсов отдается активному приложению/игре).
   - Активирует высокопроизводительную схему питания Windows (`SCHEME_HIGH_PERFORMANCE` через `powercfg`).

3. **Отключение фоновой записи и GameBar:**
   - Отключает Xbox GameDVR и фоновую запись игр (`GameDVR_Enabled = 0` в реестре).
   - Применяет политики отмены GameDVR (`AllowGameDVR = 0` в `HKLM`).

4. **Аудит настроек Steam и CS2:**
   - Автоматически находит директорию установки Steam и CS2.
   - Проверяет наличие и содержимое `autoexec.cfg`.
   - Проверяет установленные параметры запуска Steam (AppID 730).

---

## ⚠️ Безопасный запуск

Для успешного применения системных твиков (запись в `HKLM` реестра и смен схем электропитания через `powercfg`) скрипт необходимо запускать от имени **Администратора**.

### Инструкция по запуску:

1. Откройте **PowerShell** от имени администратора:
   - Нажмите `Win + X` и выберите **PowerShell (Администратор)** или **Терминал (Администратор)**.
2. Перед запуском убедитесь, что игра **Counter-Strike 2 закрыта**.
3. Разрешите выполнение скриптов в текущей сессии (если ограничено политикой):
   ```powershell
   Set-ExecutionPolicy Unrestricted -Scope Process -Force
   ```
4. Перейдите в папку со скриптом и запустите его:
   ```powershell
   cd "D:\cs2-optimizer"
   .\optimize_cs2.ps1
   ```

---

## 💡 Рекомендации после работы скрипта

- После очистки кэша шейдеров при первом запуске игры может потребоваться некоторое время на повторную компиляцию шейдеров.
- Для полной активизации сетевых и реестровых твиков рекомендуется **перезагрузить компьютер**.
- Удалите устаревшие/неподдерживаемые параметры запуска CS2 в Steam (например, `-threads`, `-high`, `-useallavailablecores`).
